Política de privacidad

Esta aplicación accede únicamente en modo lectura a los datos de YouTube Analytics del canal autorizado por su propietario.

Los datos se usan solo para generar reportes internos. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

El usuario puede revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions

Esta aplicación cumple con la Política de Datos de Usuario de los Servicios de API de Google y con los Términos de Servicio de YouTube (https://www.youtube.com/t/terms).
